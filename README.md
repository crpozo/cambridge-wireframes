# Wireframes Plataforma Cambridge

Wireframes estáticos de alto nivel (HTML/CSS, sin build) publicados con GitHub Pages.

- `index.html`: mapa de pantallas por flujo
- Una página por pantalla (`Main.html` = login)

Publicación: GitHub Pages. Opción A: Settings → Pages → Source "GitHub Actions" (el workflow `.github/workflows/pages.yml` despliega en cada push a `main`). Opción B: Settings → Pages → Deploy from branch `main` / root.

URL: https://crpozo.github.io/cambridge-wireframes/
